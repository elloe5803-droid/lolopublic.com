# 🦅 AirDroid Clone — Remote Control & Monitoring

> **Versi:** 1.0.0  
> **Status:** Production Ready  
> **Lisensi:** MIT (Modified for Educational Use)

---

## 📌 Tentang Proyek

AirDroid Clone adalah **aplikasi remote control dan monitoring** yang memungkinkan Anda mengakses perangkat Android dari jarak jauh melalui **kode akses 6 digit**.  
Dibangun 100% independen tanpa biaya berlangganan, dengan server pribadi dan panel web.

**⚠️ Peringatan:** Proyek ini dibuat untuk tujuan **edukasi dan pengujian keamanan**. Penggunaan di luar itu sepenuhnya tanggung jawab pengguna.

---

## ✨ Fitur Lengkap

| Fitur | Keterangan |
|-------|------------|
| 🔐 **Login Kode Akses** | Masuk dengan kode 6 digit, tanpa akun. |
| 📸 **Screenshot** | Ambil layar perangkat target secara instan. |
| 📷 **Kamera** | Akses kamera dan ambil foto dari jarak jauh. |
| 📍 **Lokasi GPS** | Lacak koordinat real-time. |
| 💬 **SMS Reader** | Baca semua SMS tanpa notifikasi. |
| 📇 **Kontak** | Tarik semua kontak dari perangkat. |
| 📂 **File Manager** | Jelajahi seluruh file/folder perangkat. |
| 🎙️ **Rekam Suara** | Rekam audio dari mikrofon (5 detik). |
| 📡 **Live Logging** | Semua aktivitas tercatat di server. |
| 🌐 **Panel Web** | Dashboard kontrol dari browser. |
